# 版本发布

开发与验收阶段使用 RC 候选版，例如 `0.4.0-rc.1`。后续候选版递增 RC 编号和 Android `versionCode`，以支持覆盖安装。

候选版准备流程：

1. 更新应用版本，完成格式、工程质量及相应功能验证。
2. 构建四种架构和通用签名 APK，核对版本、签名和架构。
3. 准备对应源码、SHA256 校验文件和版本说明。
4. 将 GitHub Release 设置为预发布草稿，交由项目维护者验收。

每次公开发布都需要项目维护者对该具体版本的明确批准。批准 RC 发布后，创建对应 RC 标签并公开预发布条目；批准正式版后，更新正式版本号、重新构建并发布正式条目。版本准备、功能实现和以往版本的发布授权各自对应其工作范围。
